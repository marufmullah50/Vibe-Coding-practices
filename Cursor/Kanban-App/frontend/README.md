# Kanban (frontend)

Single-board Kanban UI built with Next.js. In-memory only; refresh resets data.

## Commands

From this directory:

- `npm run dev` — development server at http://localhost:3000
- `npm run build` / `npm start` — production build and serve
- `npm run test` — Vitest unit tests
- `npm run test:e2e` — Playwright tests (install browsers once: `npx playwright install chromium`)
