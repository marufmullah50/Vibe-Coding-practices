# Vibe Coding Projects
A collection of projects built using AI-assisted coding tools.
This repository is used to experiment with different AI development workflows and quickly turn ideas into working prototypes.
## Tools

Projects in this repository may be built using:

* Claude Code
* Cursor
* GitHub Copilot (VS Code)
* Codex
* Gemini CLI
* OpenCode
* Antigravity

## Purpose

* Learn modern **AI coding workflows**
* Experiment with **coding agents and developer copilots**
* Build small applications through **vibe coding and agentic engineering**
* Compare different AI-assisted development tools
